## ⚡ Getting Started

```bash
git clone https://github.com/i-geeg-i/qr-generator.git
cd qr-generator
npm install
npm run dev
```

---

## 📦 Build

```bash
npm run build
```

---

## 🧠 Usage

1. Enter text or a URL
2. Generate QR code
3. Scan or download
